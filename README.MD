# M5Stopwatch Watch Case

M5StopwatchにApple Watch用バンドを取り付けるための、3Dプリント用ケースです。腕に沿う元の曲面を生かし、小型系Apple Watchバンド向けのスライド式受けを組み合わせた試作モデルを公開しています。

[製品紹介ページ](https://masuidrive.jp/products/m5-stopwatch-watch-case/)

**2026年10月13日現在、実物の印刷・バンドの取り付け・保持力は未テストです。実際のバンドとの適合、ロック・解除、耐久性は保証していません。**

## ダウンロード

先に試験ブロックで条件を選び、合った条件のケースを1種類だけ印刷します。単位はmm、スケールは100%です。

- [6条件のバンド受け試験ブロック（印刷向きSTL）](STL/receiver_stack_6_PRINT_axisZ.stl)
- [条件別ケース6種類のZIP](https://github.com/masuidrive/m5-stopwatch-watch-case/releases/download/v0.1.0-prototype/CURVE05_cases_6_conditions.zip)：下表で対応するIDを選びます。6個すべてを印刷する必要はありません。
- [標準ケース CURVE05 / H350相当（印刷向きSTL）](STL/m5_small_band_curve_v5_print_axisZ.stl)

リポジトリ内の標準ケースはH350（H3.50 / P5.50）相当です。ZIP内のH350も同じ嵌合形状ですが、識別用の刻印が追加されています。別の条件が合った場合は、そのIDのケースをZIPから選んでください。

## ケースについて

KawacciさんのBANDBASE2をベースに、時計の取り付け部と腕側の接触曲面を残して、両端にバンド受けを設けています。ケース単体の外形は約56.13 × 69.67 × 18.72 mmです。この寸法は組立姿勢での値で、印刷向きSTLの外接寸法とは異なります。

CURVE05では、受けの左右幅を変えずに両端の張り出しを片側2.50 mm短縮しました。全長は前版の約74.675 mmから69.675 mmになっています。

CAD形状とSTLの閉鎖性などを検査していますが、実物の嵌合・強度を確認した結果ではありません。丸み・面取りのある入口の最外縁などには薄い部分があり、全域で最小肉厚1.5 mm以上とはしていません。

## 試験ブロックの使い方

6つの条件を1部品にまとめています。Hは溝の全高、Pは係止開口の幅です。試験ブロックにある「H3.40 P5.50」などの数値刻印を読み、下表のIDに対応するケースを選んでください。H340などの短いIDはファイル名・図の識別子です。単位はmmです。

| 試験ブロックの数値刻印 | ケースID | ZIP内の印刷用STL（export/） |
| --- | --- | --- |
| H3.40 P5.50 | H340 | CURVE05_H340_print_axisZ.stl |
| H3.50 P5.50 | H350 | CURVE05_H350_print_axisZ.stl |
| H3.60 P5.50 | H360 | CURVE05_H360_print_axisZ.stl |
| H3.70 P5.50 | H370 | CURVE05_H370_print_axisZ.stl |
| H3.50 P5.35 | P535 | CURVE05_P535_print_axisZ.stl |
| H3.50 P5.65 | P565 | CURVE05_P565_print_axisZ.stl |

ZIP内の `case_parameters.csv` にも同じ対応表を収録しています。新しいケースにはIDとH/P数値の両方を彫刻しています。HとPを別の段から組み合わせず、試した組み合わせと同じケースを選んでください。どの条件も合わない場合は近いIDを推測せず、条件の追加・調整が必要です。

1. 試験ブロックを印刷して、手元のバンドで挿入・係止・解除を確認します。入れる前に解除窓の位置と、抜く操作ができることを確認してください。
2. 硬い条件を無理に押し込まず、ガタや解除の引っ掛かりも確認します。
3. 合った段の数値刻印を表で照合し、同じIDの `_print_axisZ.stl` を1種類だけ印刷します。ケースの刻印も確認し、時計を付けずに同じ挿入・係止・解除の確認を行います。
4. 欠け、白化、ひび、異常なガタなどがある場合は装着しないでください。

試験ブロックは断面の寸法候補を絞るための部品です。本体の30°傾斜や入口のC0.15面取り、周囲の支持・アクセスを完全には再現しません。ブロックに合っても本体の保持力や長期耐久性は保証されません。

## 印刷するとき

- リンクした印刷向きSTLとZIP内の `_print_axisZ.stl` は、バンドのスライド軸が造形Z方向となる候補姿勢です。スライサーの自動整列で向きが変わっていないか確認してください。
- 試験ブロックの印刷向き外形は約117.5 × 9.85 × 34.5 mmです。
- Hが大きい条件ほど溝の上下壁は薄くなります。H370の最外側入口上縁は約0.844 mmで、全域最小肉厚1.5 mm以上を保証しません。大きいHを「緩くても安全」と解釈しないでください。
- ケース外側のサポート、接地、ブリム、反りをスライサーで確認してください。サポート不要という保証はありません。
- 溝・係止部・解除窓をサポートやシームで傷つけないようにし、材料、層高、造形方向、XY補正などの条件を記録してください。
- 造形・スライス・発注先での製造可否も未検証です。時計の落下につながるおそれがあるため、十分な実物確認をしてから使用してください。

## 元のモデル

既存の `STEP/`、`STL/`、`img/`、`MOV/` には、上流のBANDBASE1、BANDBASE2、BANDBASE2A、BASEなどを残しています。これらと今回のApple Watchバンド向け試作STLは別のモデルです。
